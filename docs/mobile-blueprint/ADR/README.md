# Mobile Blueprint ADRs

Architecture Decision Records belong here when a decision changes the future mobile contract or implementation direction.

Required sections:

```text
# ADR-NNN — Title
Status: proposed | accepted | superseded
Date: YYYY-MM-DD

## Context
## Decision
## Alternatives
## Consequences
## Evidence / affected blueprint files
```

No ADR is created for a decision that is still an open question. Current unresolved decisions are in `../21-OPEN-QUESTIONS.md`.

# تطبيق إدارة عضويات الجيم

تطبيق ويب خفيف باللغة العربية لإدارة أعضاء الجيم واشتراكاتهم وتجديداتهم وتجميدهم ومدفوعاتهم. الواجهة صفحة واحدة responsive وتعمل من نفس سيرفر Node.js.

## المتطلبات

- Node.js 18.18 أو أحدث.
- قاعدة SQL Server يمكن الوصول إليها من الجهاز الذي سيشغل التطبيق.

## التشغيل المحلي

1. افتح PowerShell داخل مجلد التطبيق:

   ```powershell
   cd C:\Users\B-SMART\gym-membership-app
   npm install
   npm start
   ```

2. افتح `http://localhost:3000` في متصفح الهاتف أو الكمبيوتر.

ملف `.env` المحلي يحتوي على connection string الذي تم توفيره للتطبيق، وهو مستبعد من Git بواسطة `.gitignore`. عند النشر على جهاز آخر، انسخ `.env.example` إلى `.env` وضع بيانات الاتصال الخاصة بك.

## قاعدة البيانات

عند تشغيل السيرفر لأول مرة يتم تنفيذ `database/schema.sql` تلقائياً وإنشاء الجداول التالية:

- `members`: بيانات العضو الأساسية فقط.
- `memberships`: كل اشتراك وتجديد كسجل مستقل.
- `membership_freezes`: كل عملية تجميد كسجل مستقل، ويمكن للعضو التجميد أكثر من مرة.
- `gym_payments`: جدول مدفوعات التطبيق. تم استخدام هذا الاسم لأن قاعدة البيانات تحتوي مسبقاً على جدول `Payments` غير مرتبط بتطبيق الجيم.
- `membership_events`: سجل عمليات الإضافة والتعديل والتجديد والتجميد والاستئناف والدفع.

## التسعير

- جيم فقط: 305 ج.م شهرياً.
- جيم وكارديو: 400 ج.م شهرياً.
- قيمة الاشتراك تحسب تلقائياً بضرب السعر الشهري في مدة الاشتراك: شهر، ربع سنوي، نصف سنوي أو سنوي.
- الخصم قيمة مالية بالجنيه المصري، ويحسب المستحق بعد الخصم تلقائياً. لا يعتمد السيرفر على قيمة `amountDue` المرسلة من الواجهة.

حالة الاشتراك لا تعتمد على عمود status مخزن. يتم حسابها من تاريخ انتهاء الاشتراك وأيام التجميد:

- `active`: الاشتراك سارٍ.
- `expiring_soon`: متبقٍ 7 أيام أو أقل.
- `expired`: انتهى التاريخ الفعلي بعد احتساب التجميد.
- `frozen`: يوجد تجميد نشط حالياً.

## ملاحظات النشر

- لا ترفع `.env` إلى GitHub؛ استخدم متغيرات البيئة في الخادم المستضيف.
- افتح منفذ التطبيق خلف HTTPS أو reverse proxy في بيئة الإنتاج.
- خذ نسخة احتياطية دورية من قاعدة SQL Server.
- لا توجد مصادقة مستخدمين في النسخة الخفيفة الحالية؛ أضف login قبل فتح التطبيق على الإنترنت العام.

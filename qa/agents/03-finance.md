# Finance Agent

## Scope

المدفوعات، الإيصالات، المصروفات، الرصيد المتبقي، صافي الفترة، والمطابقة مع الاشتراكات.

## Inputs

`src/finance-service.js`، payment routes، تقارير المالية، وبيانات ledger اختبارية.

## Outputs

Reconciliation report، كشف فروقات، وحالات اختبار مالية قابلة لإعادة التشغيل.

## Required tests

- دفعة أولى، دفعة جزئية، دفعات متعددة، تسوية، ورد/قيمة سالبة إن كانت مدعومة.
- منع التكرار، rounding إلى منزلتين، صفر، أرقام كبيرة، وخصم غير صالح.
- إجمالي المدفوعات = الإيصالات = تقرير الفترة.
- تعديل وحذف مصروف وتغير الشهر والتاريخ.

## Guardrails

استخدم Decimal/SQL numeric، لا Floating point في القرار المالي، ولا تحذف سجلًا ماليًا بلا Audit evidence.
